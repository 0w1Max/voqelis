# Voqelis — модульная навигация V1

## Главное меню

После /start открывается только верхний уровень:

- 📘 Факты дня — собственное меню: новая запись, продолжить черновик,
  текущие записи, история и возврат на главную.
- 📝 Заметки — новая голосовая заметка, список заметок, возврат.
- 📅 Планировщик — существующие действия Planner, возврат.
- ✅ Список дел — личный чек-лист без дат и напоминаний: добавление одного
  дела голосом или текстом после явного действия, просмотр активных/выполненных,
  изменение, отметка выполненным/активным, удаление с подтверждением.
- 🛡 Админ-панель — только для Telegram ID владельца.

Обычным одобренным пользователям доступны только «Факты дня» и
«Список дел». Notes и Planner — только владельцу;
скрытие кнопок дополнено проверками прав в командах, навигации, приёме
и обработке аудио. Каждый пользователь видит только свои дела.

Обычная расшифровка — функция главного меню для владельца и одобренных
пользователей: достаточно прислать голосовое либо аудиофайл; бот вернёт
распознанный текст без записи в Planner, Notes или Day Facts.

Фильтры, читающие SQLite (Day Facts/Planner), должны быть асинхронными:
обычные lambda-фильтры aiogram исполняет в другом потоке и соединение
SQLite с `check_same_thread=True` нельзя использовать в нём.

Факты, экспорт за дату и другие вложенные действия используют существующие
команды и inline-кнопки. В главном меню Word/PDF больше не показываются.
Старая команда /facts по-прежнему открывает/продолжает черновик.

## Состояние и сохранность

- Независимая SQLite `todo.sqlite3` содержит пользовательские чек-листы,
  одноразовый ввод и временные подтверждения удаления.
- Таблица навигации атомарно мигрирует при добавлении `todo` и
  `todo_capture`, сохраняя user ID, секции и ревизии.
- SQLite `navigation.sqlite3` содержит Telegram user ID,
  активный раздел и его версию. Данные Planner/Notes/Day Facts не мигрируют.
- /menu и «⬅️ Главное меню» возвращают на главный экран и не уничтожают
  черновики или сессии. /start у разрешённого пользователя открывает главную.
- Экран «Факты дня» — это сначала только меню. Диктовка включается
  отдельным действием «Новая запись» или «Продолжить черновик»
  (состояние facts_capture); завершение/отмена возвращают в меню.
- Для ToDo есть `todo` (просмотр) и `todo_capture` (один ввод).
  ASR-задание закрепляется за одноразовым token; выход из модуля или
  смена экрана инвалидируют старое голосовое.
- При получении голосового фиксируется раздел и версия навигации.
  Если пользователь переключился до обработки ASR, распознанный текст не
  сохраняется в другой модуль. Нужно повторить сообщение в нужном разделе.
- Голосовое или аудиофайл на главной расшифровывается без сохранения в
  другие модули, даже если там имеется припаркованный черновик/сессия.
  В режиме «Факты дня» требуется запущенный черновик;
  для Notes — явное ожидание голосовой; для Planner — открытая сессия.
- Открытие меню модуля не создаёт никаких записей.
- Прямые команды /facts, /note, /plan продолжают работать и активируют
  соответствующий раздел. История и экспорт остаются доступны отдельно.
- Кнопки старых сообщений не должны нарушать границы активного модуля.
  Старая кнопка «🎙 Расшифровка» возвращает в главное меню. Прежнее
  состояние `transcribe` однократно переводится в `home` с повышением
  ревизии навигации, не трогая содержимое черновиков.

## Безопасность и эксплуатация

Навигация **не даёт прав**: все обработчики по-прежнему сверяют
Telegram user ID с динамическим списком разрешённых пользователей.
Административные права определяются отдельно от навигации.

Перед первым production-релизом нужно сделать SQLite-backup существующих
четырёх баз, проверить CI и deploy в изолированном Git worktree.
После установки добавить `todo.sqlite3` в список резервируемых
баз: всего их будет шесть. VPN и другие сервисы не изменяются.

Приёмка: /start, все модульные меню, выход при незавершённом черновике,
возврат к черновику, обычное голосовое, голосовое с переключением режима,
сохранение и просмотр Word/PDF, отдельные аккаунты, админ-панель.
