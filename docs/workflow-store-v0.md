# Workflow Store V0 — защищённое SQLite-хранилище конструктора

Изолированная база данных для шаблонов, черновиков и сохранённых записей.
Доступ к базе 0600. Шаблоны привязаны к owner_id, version и SHA256 fingerprint.
Повторное опубликование неизменного шаблона допустимо, перезапись существующей ревизии с другими полями запрещена.

При заполнении черновика его состояние хранится транзакционно. Каждое действие требует владельца и актуального токена, а после рестарта процесс продолжает именно прежний шаг.
Сохранение происходит только после пользовательского подтверждения. В записи сохраняются fingerprint и номер ревизии — изменение шаблона не переинтерпретирует старые данные.

В V0 реализованы WorkflowStore.publish, template, begin, draft, submit, advance, begin_edit, cancel_edit, confirm и records.
Для интеграции с Telegram понадобится авторизованный адаптер и отдельное ограничение длительности жизненного цикла.

ВАЖНО: пока библиотека не подключена к production-боту и не создаёт новую базу на VPS; это независимая архитектурная основа будущей Mini App.
Тесты специально проверяют 2 независимых шаблона, перезапуск SQLite, права файла, чужие аккаунты, повторные токены и нерушимость текущей базы Planner.
